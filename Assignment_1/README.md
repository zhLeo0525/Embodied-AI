# Assignment 1 -- Combined Report and Code

This folder contains the combined submission for Assignment 1.

| File | Description |
|---|---|
| `Assignment_1_Report.pdf` | Unified 55-page report: introduction with coverage matrix, three underactuated chapters, one manipulation chapter, conclusions, references, appendix. Every chapter has numbered Example/Section headings, step-by-step derivations, sensitivity tables for each example, implementation notes, a discussion of limitations, and answers to the notebook questions |
| `Assignment_1_Report.tex` | LaTeX source of the unified report |
| `Assignment_1_Code.zip` | All notebooks, analysis scripts, result JSONs and models from the four chapters; extracts to a single `Assignment_1_Code/` folder with its own README and `requirements.txt` |
| `Assignment_1_Submission.zip` | Report PDF + LaTeX source + code zip + this README |

Chapter order follows the assignment list:

1. Chapter 3 -- Acrobots, Cart-Poles, and Quadrotors
2. Chapter 4 -- Simple Models of Walking and Running
3. Chapter 5 -- Highly-articulated Legged Robots
4. Chapter 1 -- Introduction: Manipulation, Teleoperation and Drake

The individual, more detailed chapter reports remain in the corresponding
`Ch-3`, `Ch-4`, `Ch-5` and `Ch-1` folders.  The unified report is the main
submission document.
